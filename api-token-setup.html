QuantAI Operator Guide

API Token Setup, Step by Step

This page is a followable setup guide for the tokens used by the QuantAI day-trading scan. Work top to bottom. Add each credential to .env.local, then enable that source in the app only after the token is in place.

Recommended Start

  • Step 1: set SEC_USER_AGENT
  • Step 2: get FMP_API_KEY for news plus breakout confirmation
  • Step 3: get X_BEARER_TOKEN for social catalyst scanning
  • Step 4: add either BENZINGA_API_TOKEN or Alpaca news keys
  • Step 5: add Discord and Anthropic only if you want alerts and memo generation

Important Rules

  • Never paste keys into the React file or commit them to Git.
  • Put secrets only in .env.local.
  • Enable each source in the UI only after its token is set.
  • As of March 18, 2026, pricing and access notes below match current public docs.

1. Create Your Environment File

In the project root, copy .env.example to .env.local. Then paste the keys you collect into the matching variables below. 

SEC_USER_AGENT=quant-analyst/1.0 (your-email@example.com)
X_BEARER_TOKEN=
BENZINGA_API_TOKEN=
APCA_API_KEY_ID=
APCA_API_SECRET_KEY=
FMP_API_KEY=
ANTHROPIC_API_KEY=
ANTHROPIC_MODEL=claude-sonnet-4-20250514
DISCORD_WEBHOOK_URL=
Create .env.local before collecting tokens.
Save after every credential so you do not lose track.
Do not share screenshots of this file once it contains real secrets.

2. SEC EDGAR

This source does not use an API key. It only needs a real contact-style user agent so SEC requests identify your application properly.

SEC_USER_AGENT Free Required Base Feed
1

No signup needed

SEC EDGAR is public. You do not create an API account for this app flow.

2

Set a real contact string

In .env.local, use something like quant-analyst/1.0 (you@example.com).

3

Keep it accurate

Do not use a fake email. SEC fair-access guidance expects a real contact identity.

3. X API

Use X for social catalyst posts, rumor velocity, journalist headlines, and cashtag-based news breaks. This app currently uses recent search, not a persistent stream worker.

X_BEARER_TOKEN Pay Per Usage Social Feed
1

Open the X developer console

Go to the X Developer Portal and sign in with your X account.

2

Create a project and app

If you do not already have one, create a project, then create an app under it.

3

Open Keys and Tokens

Inside the app, find the Keys and Tokens area.

4

Copy the Bearer Token

Paste it into .env.local as X_BEARER_TOKEN=....

5

Check billing and credits

As of March 18, 2026, X documents API pricing as pay per usage. The exact cost is shown in your developer console for your project.

Public docs note a pay-per-use model and reference a 2 million Post-read monthly cap before enterprise. Treat the Developer Console as the source of truth for your actual plan.

4. Benzinga News

Benzinga is the strongest structured breaking-news source in this phase. It is a good add-on when you want cleaner tradable headlines than generic news APIs.

BENZINGA_API_TOKEN Contact Sales / Trial Breaking News
1

Request access

Open the Benzinga API site and request a trial or data-partner access for the news feed.

2

Create or confirm your Benzinga API account

You need an issued API key or token from their platform or sales flow.

3

Copy the API token

Paste it into .env.local as BENZINGA_API_TOKEN=....

4

Enable the source in the app

Once the token is saved, turn on Benzinga News in the source list.

As of March 18, 2026, Benzinga does not publicly post standard production pricing on the docs pages. Expect trial onboarding or a partner/sales conversation.

5. Alpaca News

Alpaca is useful if you already use Alpaca for trading or market data. This app uses its historical news endpoint with your market-data credentials.

APCA_API_KEY_ID APCA_API_SECRET_KEY Basic Free / Plus $99
1

Create an Alpaca account

Sign up for Alpaca if you do not already have a trading or data account.

2

Generate API keys in the dashboard

Copy both the key ID and secret. Alpaca issues them as a pair.

3

Paste both values into .env.local

Set APCA_API_KEY_ID=... and APCA_API_SECRET_KEY=....

4

Use matching credentials

Be consistent about whether you use paper or live credentials.

Current public market-data pricing shows Basic as free and Algo Trader Plus at $99/month.
Market Data Pricing Trading API Docs News Docs

6. Financial Modeling Prep

FMP is the most practical early subscription for this app because it contributes stock news, press releases, and quote-based breakout confirmation.

FMP_API_KEY Free / $22 / $59 / $149 News + Quotes
1

Create an FMP account

Open Financial Modeling Prep and create your account.

2

Open your dashboard

Your API key is shown in the account dashboard once the account is active.

3

Copy the API key

Paste it into .env.local as FMP_API_KEY=....

4

Use this source early

In this app, FMP does double duty: headline scanning and quote confirmation for breakout scoring. It is one of the highest-value first subscriptions.

As of March 18, 2026, public pricing shows Basic free, Starter $22/month, Premium $59/month, and Ultimate $149/month.

8. Discord

Discord is optional. Use it only if you want alert delivery from the app into a channel.

9. Final Checklist

Once your keys are in place, restart the local dev server so Vite reloads the server-side environment variables.

Save all keys in .env.local.
Restart with npm.cmd run dev.
Open the main app and enable only the providers you have configured.
Run a scan and confirm provider health on the dashboard.
If a provider shows disabled or offline, verify the exact env var name first.
